## 测试用例列表

### 第一阶段：基础功能测试

#### 1. 视频上传和分析
**测试步骤**：
1. 点击"选择视频文件"按钮
2. 选择一个小视频（建议 < 50MB，时长 < 2分钟）
3. 观察上传进度条
4. 等待分析完成

**预期结果**：
- ✅ 进度条正常显示 0-100%
- ✅ 上传成功提示
- ✅ 视频信息显示（文件名、时长）
- ✅ 视频自动加载到播放器

**可能问题**：
- 上传超时（timeout 设置为 10 分钟）
- 视频格式不支持（仅支持 mp4/avi/mov）
- AI 分析失败（网络问题或 API 配额）

#### 2. 视频播放
**测试步骤**：
1. 上传完成后，视频应该自动加载
2. 点击播放按钮
3. 拖动进度条
4. 观察时间显示

**预期结果**：
- ✅ 视频正常播放
- ✅ 播放/暂停按钮切换正常
- ✅ 进度条跟随播放进度更新
- ✅ 时间显示格式正确（MM:SS）

**可能问题**：
- 视频不播放（stream 端点问题）
- 进度条不动（timeUpdate 事件未触发）
- 拖动不响应（seek 功能问题）

#### 3. 快速标记笔记
**测试步骤**：
1. 播放视频到某个时间点（例如 00:30）
2. 点击"重要"/"问题"/"想法"按钮之一
3. 查看笔记列表

**预期结果**：
- ✅ 笔记立即出现在列表中
- ✅ 时间戳正确（[00:30]）
- ✅ 标签颜色正确（重要=红色，问题=橙色，想法=蓝色）
- ✅ 笔记内容为空，显示"点击编辑笔记内容"

**可能问题**：
- API 调用失败（400/500 错误）
- 笔记不显示（前端状态更新问题）
- 时间戳不正确（currentTime 获取问题）

#### 4. 编辑笔记
**测试步骤**：
1. 点击一条笔记
2. 输入内容（支持 Markdown）
3. 点击"保存"按钮

**预期结果**：
- ✅ 编辑器打开并聚焦
- ✅ 保存成功提示
- ✅ Markdown 正确渲染（代码块、列表等）
- ✅ 内容持久化（刷新页面仍存在）

**可能问题**：
- 保存失败（API 错误）
- Markdown 不渲染（react-markdown 问题）
- 内容丢失（状态管理问题）

#### 5. 点击时间戳跳转
**测试步骤**：
1. 创建几条不同时间的笔记
2. 点击笔记的时间戳

**预期结果**：
- ✅ 视频跳转到对应时间
- ✅ 如果视频暂停中，跳转后仍保持暂停

**可能问题**：
- 跳转不生效（seekTo 方法问题）
- 跳转到错误位置（时间单位不一致）

### 第二阶段：AI 功能测试

#### 6. AI 快速提问（无截图）
**测试步骤**：
1. 切换到"AI 助手"标签页
2. 输入问题（例如："这个视频讲了什么？"）
3. 点击"发送"按钮

**预期结果**：
- ✅ WebSocket 连接成功
- ✅ 问题显示在对话历史中
- ✅ AI 回答逐字流式显示
- ✅ 回答完成后停止加载动画
- ✅ 回答内容合理且与视频相关

**可能问题**：
- WebSocket 连接失败（端口/路径错误）
- 错误提示"缺少必要参数"（已修复）
- 流式响应不显示（onChunk 回调问题）
- AI 返回空内容（API 问题）

#### 7. AI 截图提问
**测试步骤**：
1. 播放视频到有意义的画面
2. 输入问题（例如："这个画面展示了什么？"）
3. 点击"截图提问"按钮

**预期结果**：
- ✅ 自动捕获当前帧
- ✅ 问题下方显示截图
- ✅ AI 回答结合图像内容
- ✅ 回答更具体，提到图像细节

**可能问题**：
- 截图失败（getFrame API 错误）
- 截图不显示（base64 格式问题）
- AI 未使用图像信息（vision 模型未启用）
- 截图很慢（帧提取性能）

#### 8. 对话历史
**测试步骤**：
1. 连续提问多个问题
2. 滚动查看历史消息
3. 点击消息中的时间戳

**预期结果**：
- ✅ 所有消息按时间顺序排列
- ✅ 用户消息和 AI 消息样式区分明显
- ✅ 自动滚动到最新消息
- ✅ 点击时间戳可跳转视频

**可能问题**：
- 消息顺序错误
- 滚动不自动（scrollToBottom 失效）
- 时间戳跳转不工作

**预期结果**：
- ✅ 显示友好的错误提示
- ✅ 不会崩溃或白屏
- ✅ 可以恢复操作

**可能问题**：
- 错误提示不清晰
- 应用崩溃
- 状态混乱

## 调试技巧

### 前端调试
1. **查看 Network 面板**：
   - XHR/Fetch：查看 API 请求状态
   - WS：查看 WebSocket 消息
   - Media：查看视频加载

2. **查看 Console 面板**：
   - 红色错误信息
   - 网络请求失败
   - 组件渲染错误

3. **React DevTools**：
   - 查看组件状态
   - 追踪 props 变化

### 后端调试
1. **终端日志**：
   - 查看请求日志
   - 查看错误堆栈

2. **API 测试**：
   - 使用 curl 或 Postman 测试单个端点
   - 验证返回数据格式

3. **数据文件检查**：
   - 查看 `backend/data/videos.json`
   - 查看 `backend/data/notes.json`

## 常见问题快速查询

| 现象 | 可能原因 | 检查方法 |
|-----|---------|---------|
| 页面空白 | TypeScript 导入错误 | F12 Console 查看错误 |
| 视频不播放 | stream 端点问题 | Network 查看视频请求状态 |
| AI 不响应 | WebSocket 未连接 | WS 面板查看连接状态 |
| 笔记不保存 | API 调用失败 | Network 查看请求响应 |
| 进度条不动 | timeUpdate 未触发 | Console 添加 log 调试 |

## 性能指标

### 预期性能
- 视频上传（100MB）：< 30 秒
- 视频分析：< 2 分钟
- 帧提取：< 1 秒
- AI 响应延迟：< 3 秒
- 笔记操作：< 500ms
- 页面加载：< 2 秒

### 性能优化建议
1. 视频缓存机制（已实现）
2. 懒加载组件
3. 虚拟滚动（笔记列表很长时）
4. 防抖输入（AI 问答输入）
5. 图片压缩（截图功能）
