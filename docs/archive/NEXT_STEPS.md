## 🔄 当前阶段：测试后端功能

在开发前端之前，我们先测试后端的核心功能是否正常工作。

### 阶段 1：测试后端 API（30分钟）

#### 1.1 测试健康检查 ✅
- 访问 http://localhost:8000
- 状态：已完成

#### 1.2 测试视频上传和处理
**目标**：验证视频能否正常上传、处理、分析

**操作步骤**：
1. 准备一个测试视频（**建议 < 1 分钟的短视频**）
2. 在 API 文档页面测试上传
3. 观察处理过程
4. 检查返回结果

**具体操作**：
```
1. 打开 http://localhost:8000/docs
2. 找到 "POST /api/videos/upload" 接口
3. 点击 "Try it out"
4. 点击 "Choose File" 选择视频
5. 点击 "Execute"
6. 等待处理完成（会显示进度）
```

**期望结果**：
```json
{
  "video_id": "abc-123-def",
  "duration": 45.2,
  "analysis": {
    "summary": "视频主题...",
    "topics": ["知识点1", "知识点2"],
    "chapters": [...]
  }
}
```

#### 1.3 测试笔记功能
**目标**：验证笔记的创建、查询、更新、删除

**操作步骤**：
1. 使用上一步得到的 `video_id`
2. 创建笔记
3. 查询笔记
4. 更新笔记
5. 导出笔记

**具体操作**（在 API 文档页面）：
```
1. POST /api/notes - 创建笔记
   参数：
   {
     "video_id": "你的video_id",
     "timestamp": 10.5,
     "type": "important",
     "content": "这是测试笔记"
   }

2. GET /api/notes/{video_id} - 查询笔记

3. PUT /api/notes - 更新笔记

4. GET /api/notes/export/{video_id} - 导出笔记
```

#### 1.4 测试视频帧截取
**目标**：验证能否获取指定时间的视频帧

**操作步骤**：
```
GET /api/videos/{video_id}/frame?timestamp=5.0
```

应该返回 base64 编码的图片。

### 阶段 2：前端开发（2-3 周）

一旦后端测试通过，我们开始前端开发。

#### 2.1 前端技术栈确认

**推荐方案**（简单快速）：
```
- React 18 + TypeScript
- Vite（构建工具）
- Ant Design（UI 组件库，开箱即用）
- video.js（视频播放器）
- Axios（HTTP 请求）
```

**或者更轻量的方案**：
```
- React + JavaScript（不用 TypeScript）
- 原生 CSS（不用 UI 库）
- HTML5 video 标签（不用 video.js）
```

#### 2.2 前端开发步骤

##### 步骤 1：创建项目结构（1天）
```bash
# 创建前端项目
npm create vite@latest frontend -- --template react-ts

# 安装依赖
cd frontend
npm install
npm install axios antd video.js react-markdown
```
